# FastFood Manager

Sistema CRUD para la gestión de un negocio de comida rápida.
Práctica 1 — Gestión de la Configuración del Software (8.º semestre).

## Descripción

Aplicación web del lado del cliente desarrollada con HTML, CSS y JavaScript puro.
Permite administrar productos del menú, clientes y pedidos, con un panel de
estadísticas. La información se persiste en `localStorage` del navegador.

## Tecnologías

- HTML5
- CSS3
- JavaScript ES6+
- localStorage API

## Cómo ejecutarlo

1. Clonar el repositorio.
2. Abrir el archivo `index.html` con cualquier navegador moderno.
3. Opcionalmente, hacer clic en *Cargar datos demo* desde el Dashboard.
